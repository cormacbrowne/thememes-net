# innovation/: new games and playable meme formats (owner: innovation-lead)

- `ideas.md`: the backlog, one line per idea, with score and status.
- `concepts/`: one concept card per idea worth writing up (`concepts/TEMPLATE.md`).

Flow: `/new-idea` → concept card → `/pitch` → Cormac go/no-go (`ops/decisions.md`) → dispatcher routes the build → retro-games-producer builds → QA → ship.

**Original only:** genres and mechanics are fine; recreating a specific existing game's name, characters, art, levels or music is not.
